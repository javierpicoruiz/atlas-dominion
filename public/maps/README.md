# Geographic background

`europe.geojson` is a regional subset of Natural Earth's 1:50m country polygons, retrieved 2026-09-24 from:
https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson

Only country name and geometry are retained. These are background geography, not campaign territories or additional game cities.

Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/

MapLibre's attribution control credits Natural Earth. The GeoJSON and MapLibre worker are precached with the PWA, so the geographic map works offline without tile, font, token or API dependencies.
